# چک‌لیست پروژه‌های طراحی (نسخه مستقل)

برنامه‌ای که پروژه‌ها رو فقط روی همون دستگاهی که بازش کردی ذخیره می‌کنه. به هیچ سرور یا حساب آنلاینی وصل نیست.

## محتویات پوشه

- `index.html`: خود برنامه
- `manifest.webmanifest` و `icon-*.png`: اطلاعات و آیکون نصب روی گوشی
- `sw.js`: کش آفلاین (بعد از اولین باز شدن، بدون اینترنت هم کار می‌کنه)
- `fonts/`: فونت‌ها (وزیرمتن و لالزار)، تا بدون اینترنت هم ظاهر برنامه درست بمونه

## نصب روی گوشی

برای اینکه مرورگر اجازه نصب بده، پوشه باید یک بار از یه آدرس وب (https) باز بشه. هر هاست رایگان فایل ثابت مثل Netlify، Cloudflare Pages یا GitHub Pages جواب می‌ده؛ کل این پوشه رو همون‌طور که هست آپلود کن. بعد از اون:

**اندروید (Chrome):** آدرس رو باز کن، منوی سه‌نقطه، «Install app» یا «Add to Home screen».

**آیفون (Safari):** آدرس رو توی Safari باز کن، دکمه اشتراک‌گذاری، «Add to Home Screen».

بعد از نصب، برنامه تمام‌صفحه و با آیکون خودش باز می‌شه و داده‌ها روی همون گوشی می‌مونن.

## نکته مهم درباره داده‌ها

داده‌ها توی حافظه مرورگر همون گوشی نگهداری می‌شن. اگه اطلاعات سایت‌ها رو از تنظیمات مرورگر پاک کنی یا برنامه رو حذف کنی، پروژه‌ها از بین می‌رن. برای همین:

- هر چند وقت یک‌بار دکمه **پشتیبان‌گیری** (زیر آمار) رو بزن و فایل رو جایی نگه دار (Files، تلگرام، ایمیل).
- برای برگردوندن، دکمه **بازیابی** رو بزن و همون فایل رو انتخاب کن. پروژه‌های فعلی حذف نمی‌شن و با فایل ادغام می‌شن.

فایل پشتیبان همون چیزیه که بعداً برای انتقال به لپ‌تاپ یا همگام‌سازی هم به کار می‌آد.

## نکته برای به‌روزرسانی

اگه فایل‌ها رو عوض کردی، عدد `CACHE` بالای `sw.js` رو یکی بالا ببر (مثلاً `v2`) تا گوشی نسخه جدید رو بگیره.
